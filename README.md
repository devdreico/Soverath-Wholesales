# Soverath Wholesales

Portal principal del ecosistema Soverath Wholesales: una experiencia premium, minimalista y enfocada en la presentación de cinco tiendas afiliadas bajo una misma identidad de marca.

## Descripción

Soverath Wholesales es una landing page central diseñada para presentar un conjunto de tiendas especializadas con una estética moderna, visualmente cuidada y optimizada para dispositivos móviles. La marca combina una identidad sobria con animaciones suaves, vidrio translúcido y una navegación directa hacia cada boutique afiliada.

## Tiendas del ecosistema

- Botane — Salud natural
- Viking Dogs — Gadgets para perros
- Lun & Lou — Belleza y cuidado femenino
- Esturel — Tecnología y hardware
- Knifopics — Cocina y alimentos

## Stack tecnológico

- React 19
- Vite 8
- JavaScript
- CSS moderno con glassmorphism y animaciones

- Node.js 18+
